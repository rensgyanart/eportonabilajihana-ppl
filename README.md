# Panduan Portofolio PPL Mandiri & Terbimbing - Nabila Jihan Athifah, S.Ds.

Website portofolio ini dibangun khusus sebagai **template terstruktur siap pakai** untuk **Nabila Jihan Athifah, S.Ds.** (PPG Calon Guru Gelombang 1 Tahun 2026 - Bidang Studi Desain Komunikasi Visual) di **FKIP Universitas Sarjanawiyata Tamansiswa (UST)** dan **[Slot Sekolah Mitra PPL]**.

Arsitektur visual dan interaksi mempertahankan estetika **Aurevo Style** (`aurevo.framer.website`), sementara seluruh **struktur kategori, alur siklus KBM, dokumen tagihan LMS UST, dan riset PTKK** meminjam kerangka kerja terverifikasi milik **Reno Malik Akbarkhan, S.Ds.** ([Portofolio_PPL_Reno](file:///c:/Users/rensgyanart/Documents/College/Portofolio_PPL_Reno)). Seluruh teks narasi spesifik, informasi tempat PPL, Guru Pamong, DPL, serta angka data penelitian telah diubah menjadi **slot template terpandu** sehingga Nabila Jihan dapat dengan mudah mengisi data sekolah dan pengalaman PPL aslinya sendiri.
